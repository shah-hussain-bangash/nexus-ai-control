# Synthetic long-term UI harness — 0.9.0

The harness has no real login or credentials. It includes the 216-function map and shared screen designer, 18 operational experiences, in-memory plan edits/revisions and effect-free previews. Reload resets edits; legacy runtime mutations are blocked. Full-scope export includes only the synthetic snapshot and your in-memory design changes.

Run npm ci then npm run dev to preview locally. The real backend/frontend provide authenticated database persistence. Planned endpoints shown in function contracts are not called or registered by this harness. No cloud, identity, document processing or provider execution occurs.
