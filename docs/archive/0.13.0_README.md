# NEXUS AI Control — 0.13.0

Enterprise Agentic AI Governance, Security & Operations Platform.

This release adds **persistent PDF/DOCX/image intake, separate-process extraction, optional scanned-PDF/image OCR, explicit source review and scoped publication** to the working document library. The dashboard includes job status, text preview, original SHA-256 provenance, retry/cancel/archive controls and uncertain-request recovery. Clear light/dark styles and large text are retained.

Windows: read [Upgrade guide](docs/UPGRADE_0_13_0.md), then run `scripts\start.cmd` from the project root and keep its terminal open. Use the newly printed URL. Migration adds schema 8 without resetting existing accounts/data. OCR is disabled by default; searchable PDFs and DOCX work without Tesseract.
