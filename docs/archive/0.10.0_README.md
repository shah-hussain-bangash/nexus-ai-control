# NEXUS AI Control — 0.10.0

Enterprise Agentic AI Governance, Security & Operations Platform.

This release adds two working, database-backed dashboard areas: **Agent execution** for bounded durable workflows and **Document library** for UTF-8 text ingestion, reader permissions and cited lexical search. They use authenticated, tenant-scoped APIs. Existing sign-in, policy decisions, independent approvals, synthetic business execution, model gateway and the 216-function design inventory remain available.

Start Windows with `scripts\start.cmd` and keep its terminal open. Use the printed URL. Read [Upgrade guide](docs/UPGRADE_0_10_0.md) before replacing files: this release migrates the database to schema 6 and preserves existing accounts and project records.

The application source is backend/ and frontend/. demo-preview/ is an isolated, synthetic UI harness: new runtime mutations are blocked there. Run the real application to create workflows or upload documents. Planned design screens remain visibly separate from their working runtime links.

**This is an engineering platform under development, not a fully accepted production deployment.** Live customer adapters, enterprise infrastructure and independent security/load/accessibility/restore acceptance remain open. No live deployment was changed by this source release.
