# NEXUS AI Control — 0.9.0 long-term enterprise UI scope

Enterprise Agentic AI Governance, Security & Operations Platform.

This update adds the remaining capabilities to the UI design before backend development: **216 function designs across 18 modules**, with 648 feature-screen controls, intended roles, journeys, failure states, planned API contracts and manual UI review. The 18 dedicated operational experiences from 0.8.0 remain available.

Open **Platform function map → find a capability → Open function screen**. Configure and review it, then **Save revision** in the studio to persist the plan. Each module also has a Function catalog section. The UI uses shared typed screen patterns with feature-specific definitions; it does not implement the 216 live services.

Start on Windows using `scripts\start.cmd`. Read [UPGRADE_0_9_0.md](docs/UPGRADE_0_9_0.md) before updating. Preserve private settings, databases and backups. Schema remains 5; no account reset is required.
